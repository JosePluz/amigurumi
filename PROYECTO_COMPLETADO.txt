📋 PRÓXIMOS PASOS (30 MINUTOS):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1️⃣  npm install
       → Instalar dependencias Node

  2️⃣  npm start
       → Ejecutar localmente en http://localhost:3000

  3️⃣  Probar admin panel
       → Click 🔐 Admin
       → Contraseña: admin2024
       → Agregar producto de prueba

  4️⃣  git init && git add . && git commit -m "Initial"
       → Preparar repo local

  5️⃣  Crear repo en GitHub
       → https://github.com/new
       → Nombre: amigurumis

  6️⃣  git push a GitHub
       → Subir código

  7️⃣  Deploy en Render
       → https://render.com → New Web Service
       → Conectar repo GitHub
       → npm start (start command)
       → npm install (build command)

  8️⃣  Agregar variables de entorno en Render
       → PORT=3000
       → NODE_ENV=production
       → ADMIN_PASSWORD=tu_contraseña

  9️⃣  ¡Listo! Tu sitio estará en vivo en Render
